🎬 Video → Audio → Transcripción (Groq)

Extraé el audio de un video, descargalo en MP3, transcribilo con Whisper de Groq y traducilo al español usando modelos de Groq. Todo se procesa en el propio dispositivo, salvo la transcripción y la traducción que usan la API de Groq.

1 Configuración de Groq

La clave se usa solo en este dispositivo, para llamar a api.groq.com directamente desde el navegador. No se guarda ni se envía a ningún otro lado. Se pierde al cerrar la app (podés volver a pegarla la próxima vez).

⚠️ Recomendación: la API Key que ves ya está expuesta. Generá una nueva en console.groq.com y reemplazala antes de usar la app.

2 Cargar video

Tamaño máximo recomendado: 500 MB. Si el navegador no puede leer el formato (por codec no compatible), se usará automáticamente ffmpeg (descarga ~25 MB la primera vez).

3 Audio extraído

4 Transcripción

5 Traducción al español

Hecho para uso con WebIntoApp. Requiere conexión a internet: la primera vez descarga el motor de conversión de audio (~25 MB) y luego usa la API de Groq para transcribir (Whisper) y traducir (modelos de chat).
